# data/

Files here are generated by the pipeline and are not committed.

| File | Produced by | Contents |
|---|---|---|
| `arc_raiders.db` | `python -m hlo.collect` | SQLite: videos, comments (with reply threading), search state |
| `comments_clean.csv` | `hlo.data.build_dataset` | analysis dataset (English, ≥3 words, deduplicated) with LLM context fields |
| `labels_llm.csv` | `hlo.label.llm_labeler` | game_related / target / category / sentiment / confidence / reasoning per comment |
| `labels_roberta.csv` | `hlo.label.roberta_baseline` | RoBERTa class probabilities and label |
| `gold_to_annotate.csv` | `hlo.eval.gold export` | blind annotation sheet |
| `release/comments_labels.csv` | `scripts/export_release.py` | public release (no text) |

To migrate the course-project files, rename `comments_for_analysis.csv` to `comments_clean.csv` and `comments_llama_labeled.csv` to `labels_llm.csv`. The old CSV calls the parent column `parent_text`, which is what the code expects now. The old labels were produced without parent context (see `docs/CHANGES.md`), so relabel replies before the final run.
